# Insurance Quote App
- Stack: Next.js 14+, TypeScript, Tailwind, SQLite
- Shared form state between form UI and chat helper
- Validate: coverage 50k-500k, deductible 1k-5k, materials Straw|Wood|Brick|Steel
- Straw quotes must be rejected with a clear message
- Keep scope to ~1 hour; prefer working vertical slice over polish
- No auth, no tests unless time remains
